 Phase-by-phase implementation process:
Each phase maps directly to a section of the configs above. Complete and verify one phase fully before starting the next — this is what your before/after evidence and incident report should be structured around.
Phase 1 — VLAN design and creation
Create VLANs 10, 20, 30, 40, 50, 60, 99, and 999 on DSW1, DSW2, and all three ASWs (Section 11).
Name every VLAN to match Section 4 so show vlan brief output is self-documenting.

Verify:  show vlan brief 
 ·            show interfaces status
Phase 2 — Build access and distribution switching layer
Cable each ASW with two uplinks — one to DSW1, one to DSW2.
Cable DSW1 and DSW2 together with two links for the future EtherChannel.
Bring up all access ports and confirm link lights / status before applying VLAN assignments.

Verify:   show interfaces status  ·
               show cdp neighbors
Phase 3 — Configure trunks, allowed VLANs, and native VLAN
Apply the trunk blocks from Section 11 on every inter-switch link.
Set native VLAN 999 on every trunk — confirm it matches on both ends of each link to avoid a native VLAN mismatch.
Restrict the allowed VLAN list on each ASW uplink to only the VLANs that floor actually uses.
Verify:  show interfaces trunk  ·  
             show interfaces <int> switchport
Phase 4 — Configure EtherChannel between distribution switches
Apply channel-group 1 mode active on both members on DSW1 and DSW2 (LACP active/active).
Confirm the port-channel forms before moving on — a common fault here is one side set to passive.

Verify: show etherchannel summary 
 ·            show interfaces port-channel 1
Phase 5 — Set STP root primary/secondary per VLAN group and PortFast
Apply the split root configuration from Section 3.2 on DSW1 and DSW2.
Enable PortFast and BPDU guard on every access-facing port on all three ASWs.
Enable root guard on DSW1/DSW2 ports facing the access layer.

Verify: show spanning-tree vlan <id>  
          ·  show spanning-tree summary
Phase 6 — Configure inter-VLAN routing with HSRP
Apply router-on-a-stick sub-interfaces and HSRP groups from Section 11.1–11.2 on both routers.
Add track 1 on the uplink interface on both routers so HSRP reacts to link failure, not just router failure.
Configure DHCP pools for the five user VLANs.

Verify: show standby brief  · 
             show ip interface brief  · 
              show ip dhcp binding
Phase 7 — Apply port security, DHCP snooping, ARP inspection, and ACLs
Apply port security on every access port (Section 11.5–11.7).
Enable DHCP snooping and Dynamic ARP Inspection on DSW1, DSW2, and trust the uplink ports (Section 11.3–11.4).
Apply the ACL-VLANxx-IN access lists on both routers (Section 10) and the NOC-MGMT-ONLY access-class on every device's VTY lines.

Verify: show port-security  
             ·  show ip dhcp snooping  
·              show ip arp inspection  · 
               show access-lists
Phase 8 — Redundancy, access-control, and documentation testing
Shut down each distribution switch in turn and confirm every access switch keeps connectivity through the other.
Shut down R-CAMP1's uplink and confirm HSRP fails over to R-CAMP2 within a few seconds.
Test every deny/allow pair in the Section 10 matrix with ping and document pass/fail.
Capture before/after show-command output for every phase and write up any faults encountered in the incident report.
Verify: show standby brief   ·
              show spanning-tree vlan <id>
  ·            ping / traceroute across VLAN pairs
